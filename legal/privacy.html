隐私政策

更新日期：2026年10月31日　|　生效日期：发布之日起生效

摘要：我们仅收集提供服务所必需的信息，不出售你的个人数据，并采取合理措施保护你的隐私。你对自己的账号与内容享有查询、更正、删除和导出权利。

1. 我们收集的信息

  • 注册信息：账号名、密码（加盐哈希存储，不存明文）、邮箱地址（如你提供）。
  • 使用信息：登录时间、IP 地址、访问页面、设备类型与操作系统版本。
  • 上传内容：你提交的视频文件、封面图片及相关元数据（标题、描述、上传时间）。
  • 客户端信息：如你使用本项目的桌面端/移动端客户端，我们可能收集设备标识符、崩溃日志与性能数据，用于改进稳定性，此类数据尽量匿名化。
  • 本地存储：网站与客户端可能使用本地存储或 Cookie 维持登录状态与偏好设置。

2. 信息的用途

  • 提供账号登录、视频播放、上传与管理等核心服务。
  • 识别异常登录、防止滥用、欺诈与攻击。
  • 处理你的数据查询、更正、删除与导出请求。
  • 基于匿名化数据改进产品性能与用户体验。

3. 信息共享与披露

  • 我们不会出售你的个人信息。
  • 未经你同意，不向第三方分享可识别个人身份的信息，以下情形除外：
    • 法律法规要求，或司法、行政机关依法调取。
    • 为保护本站、用户或公众安全，防止欺诈、攻击或违法行为。
    • 在必要范围内与托管、存储服务商（如 GitHub Pages、云存储）共享，其受保密义务约束。

4. 数据安全

  • 密码采用加盐哈希存储，服务端不保存明文密码。
  • 数据传输使用 HTTPS 加密（建议开启 Enforce HTTPS）。
  • 采取访问控制、日志审计等措施保护数据，但互联网传输无法保证绝对安全，请你理解该固有风险。

5. 你的权利

  • 查询、更正你的账号信息。
  • 删除你的账号及关联内容（注销后不可恢复）。
  • 导出你的个人数据副本。
  • 行使上述权利请联系：此处填写你的联系邮箱。

6. Cookie 与本地存储

我们使用 Cookie 与本地存储维持登录状态、记住偏好设置，不用于跨站广告追踪。你可在浏览器或客户端设置中清除，但清除后部分功能可能无法正常使用。

7. 第三方服务

本站可能使用第三方托管、统计或视频播放服务（如 GitHub Pages、YouTube / Bilibili 嵌入）。这些服务有其独立隐私政策，建议你查阅；第三方内容不适用本站隐私政策。

8. 未成年人保护

未满 14 周岁的未成年人应在监护人同意下使用本服务。我们不会故意收集未成年人的个人信息；如发现误收集，将及时删除。

9. 政策变更

本政策可能更新，重大变更将通过站内通知或你留存的联系方式告知。继续使用本站服务视为接受修订后的版本。
