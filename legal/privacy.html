隐私政策

生效日期：2026年10月31日

摘要：我们仅收集提供服务所必需的信息，不出售你的个人数据。密码加密存储，传输全程 HTTPS。你对自己的数据拥有查询、更正、删除的权利。

1. 我们收集的信息

  • 注册信息：账号名、密码（加盐哈希存储，不存明文）、邮箱地址（如填写）。
  • 使用信息：登录时间、IP 地址、访问页面、设备类型、操作系统及版本。
  • 上传内容：你通过本地上传提交的视频文件、封面图片及相关元数据（标题、描述等）。
  • 客户端信息：如你使用本项目的桌面端或移动端客户端，我们可能收集设备标识符、崩溃日志以改进稳定性与兼容性。
  • 本地存储：浏览器或客户端使用本地存储 / Cookie 维持登录状态与用户偏好。

2. 信息如何使用

  • 提供账号登录、视频播放、上传与管理等核心功能。
  • 识别异常登录、防止滥用、刷量与恶意攻击。
  • 处理你的数据查询、更正、删除与账号注销请求。
  • 基于匿名化崩溃日志改进客户端性能与用户体验。

3. 信息共享与披露

  • 我们不会出售你的个人信息。
  • 未经你同意，不向第三方分享可识别个人身份的信息，以下情况除外：
    • 法律法规要求，或司法/行政机关依法调取。
    • 为保护本站、用户或公众安全，防止欺诈或网络攻击。
    • 与托管服务商（如 GitHub Pages、云存储提供商）在必要范围内共享，其受保密义务约束。

4. 数据安全

  • 密码采用加盐哈希算法存储，服务器不保留明文。
  • 所有数据传输使用 HTTPS 加密通道。
  • 采取访问控制、日志审计、定期备份等措施保护数据。
  • 互联网传输无法保证 100% 安全，但我们会持续升级防护。

5. 你的权利

  • 查询与更正：随时查看和修改你的账号信息。
  • 删除与注销：注销账号后，所有关联数据及上传内容将被清理（不可恢复）。
  • 数据导出：可联系我们获取你的个人数据副本。
  • 联系邮箱：此处填写你的联系邮箱

6. Cookie 与本地存储

我们使用 Cookie 和本地存储维持登录状态、记住播放偏好。不用于跨站广告追踪。你可在浏览器或客户端设置中随时清除。

7. 第三方服务

  • 本站托管于 GitHub Pages，其隐私实践适用 GitHub Privacy Statement。
  • 嵌入的 B站、YouTube 等第三方播放器可能由其平台在自身隐私政策下收集播放行为数据（如设备信息、Cookie、观看动作），本站不控制该类收集。
  • 第三方内容与服务有其独立隐私政策，建议你在使用前查阅。

8. 未成年人保护

未满 14 周岁的未成年人应在监护人同意下使用本服务。我们不会故意收集未成年人的个人信息。如监护人发现相关情况，可联系我们要求删除。

9. 政策变更

本政策可能随时更新，重大变更将通过站内通知或邮件告知。更新后发布即生效，继续使用本站服务视为接受修订后的版本。
