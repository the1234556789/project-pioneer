关于 Project Pioneer

Project Pioneer 是一个纯前端视频分享平台演示项目，支持 B 站视频嵌入和本地视频播放，提供用户注册登录、视频发布、评论互动等功能。

功能特性

  • 统一登录/注册系统，全站状态互通
  • B 站视频嵌入播放 + 本地视频上传播放
  • 视频发布与管理（通过 upload.html）
  • 评论系统（本地存储，支持回复和点赞）
  • 用户个人主页，展示发布作品
  • 响应式设计，适配移动端和桌面端

技术栈

纯 HTML + CSS + JavaScript，数据存储在浏览器 localStorage 中，无需后端服务器。
